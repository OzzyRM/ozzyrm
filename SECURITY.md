# Security Policy

OzzyRM is a **local / trusted-host** schema documentation toolkit.

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | Yes |
| < 0.3   | Best effort |

## Reporting a vulnerability

**Do not** open a public issue with exploit details.

Use GitHub **Security Advisories** → *Report a vulnerability* on this repository, or follow the process in [`security/REPORTING.md`](./security/REPORTING.md).
